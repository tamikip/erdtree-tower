# 黄金树爬塔 v94 安装教程

## 安装前

- Windows 64 位，Windows 安装在 `C:\Windows`；Steam 已安装《艾尔登法环》本体，不需要 DLC。
- 本包仅匹配已验证的 `eldenring.exe` 文件版本 **2.7.2.0**，启动器同时校验文件哈希。游戏更新后若提示版本不匹配，请使用适配版本的 MOD。
- 内含爬塔 DLL、场景和 UI 资源、Mod Engine 3、无缝入口所需的 Mod Engine 2。不包含无缝 MOD 本体。
- **无缝入口已验证单人运行及骨灰召唤；多人战斗同步为可选验证模式，动态敌人复制尚未经过双人验证，不能视为完整联机版本。**
- 本次包含武器强化追赶、护符一次升至最高阶，以及动态 Boss 直接绑定原生血条的修复。Boss 血条实机显示仍待验证。

## 1. 解压

完整解压 ZIP，例如放在 `D:\Mods\ErdtreeTower`。不要在压缩包内直接运行，也不要覆盖到游戏目录。路径中不要包含单引号。

打开 Steam → 游戏属性 → 已安装文件 → 浏览，进入含有 `eldenring.exe` 的 `Game` 文件夹，复制地址栏路径。

## 2. 单机启动

1. 打开 Steam，退出已运行的游戏。
2. 双击 `Start-Solo.cmd`。
3. 首次启动会要求粘贴上面的 `Game` 文件夹路径，回车即可。路径通过检查后保存到 `GamePath.txt`，以后不必重复输入。
4. 创建爬塔角色，进入大赐福后与爬塔 NPC 交互开始。

单机入口按离线模式启动，独立存档名为 `ER_TOWER_PREVIEW.sl2`。不要将爬塔角色转入原版在线模式。

## 3. 从无缝入口启动

1. 先单独安装 **Seamless Co-op v2.0.1**：将其 `ersc_launcher.exe` 和完整的 `SeamlessCoop` 文件夹放入游戏的 `Game` 目录。下载页：https://www.nexusmods.com/eldenring/mods/510
2. 在 `Game\SeamlessCoop\ersc_settings.ini` 中设置自己的 `cooppassword`。本包不携带任何人的密码。
3. 打开 Steam，退出游戏和其他启动器，双击本包的 **`Start-Seamless.cmd`**。首次使用同样输入游戏目录。
4. 游戏运行期间保留启动窗口。
5. 进入角色后坐一次赐福即可获得无缝联机道具。

此入口通过 ME3 依次加载无缝 `ersc.dll`、爬塔 DLL 和场景资源。直接双击游戏目录的 `ersc_launcher.exe` 不会自动加载本包。

启动时读取游戏目录中的无缝配置，保留联机密码，在包内生成独立副本；原配置不改动，也不向游戏目录安装 `dinput8.dll`。继续使用原有爬塔联机存档扩展名 `ertowercoop`；指定实验同步配置时使用 `ertowerparty`。

普通爬塔无缝入口的存档扩展名为 `ertowercoop`，与普通无缝和单机爬塔存档分开。不要通过改后缀混用存档。该入口默认不开启多人同步验证。

## 4. 多人战斗验证（可选）

需要两名玩家、相同版本的本包和无缝 MOD。详细步骤见包内 `联机战斗验证.md`。

房主在本包目录打开 PowerShell，填入自己的局域网或 VPN IPv4：

```powershell
.\New-PartyConfig.ps1 -HostAddress 192.168.1.10
.\Start-Seamless.cmd -PartyConfig .\party-config\host.json
```

把生成的 `guest.json` 私下交给队友，队友放在包根目录后运行：

```powershell
.\Start-Seamless.cmd -PartyConfig .\guest.json
```

双方仍须通过无缝道具进入同一房间。验证模式使用独立的 `ertowerparty` 存档，日志位于 `seamless-entry\party-runtime`。只开放战斗节点；商店、营地、宝箱和问号事件暂时拦截。断线、领奖中断或无法确认敌人复制时停止推进，不支持自动恢复战斗。配置含连接凭据，不要公开。

## 更新与备份

更新前退出游戏，将新包解压到新目录。备份 `%APPDATA%\EldenRing` 中的存档，以及旧 MOD 目录内的 `tower-*` 进度文件和 `seamless-entry\runtime`。

如需保留当前爬塔进度，只将旧目录的 `tower-*` 进度文件复制到新包对应位置；不要复制日志、`runtime\scene-assets` 目录链接、旧 DLL 或旧配置。`GamePath.txt` 可以保留。游戏本体存档不在此压缩包中。

## 常见问题

- **找不到游戏**：删除或修改本包的 `GamePath.txt`，重新选择包含 `eldenring.exe` 的 `Game` 目录。
- **缺少文件**：重新完整解压，检查安全软件是否隔离了文件；不要只复制 DLL。
- **无缝版本不匹配**：本包固定匹配 v2.0.1 的已验证 DLL，不支持直接替换成其他版本。
- **提示已有 dinput8.dll**：先退出游戏。本启动器不会覆盖其他 MOD 的加载器，应先确认文件来源，再处理冲突。
- **强制关闭启动窗口后无法再次启动**：先退出游戏，将 `seamless-entry\ersc_settings.before-launch.ini` 恢复为游戏目录的 `SeamlessCoop\ersc_settings.ini`。只有确认游戏目录 `dinput8.dll` 与本包 `seamless-entry\dinput8.dll` 的 SHA256 相同，才删除游戏目录那一份；不要删除来源不明的 DLL。
- **反馈错误**：提供错误截图和日志。单机日志在包根目录 `tower-preview.log`；无缝日志在 `seamless-entry\runtime\tower-preview.log`。不要发送含密码的 `ersc_settings.before-launch.ini` 或 `ersc_settings.ini`。

## 卸载

正常退出游戏，等待启动窗口结束后删除 MOD 文件夹即可。无缝 MOD 由你另行安装，本包不会替你卸载。备份存档和进度后再删除。
